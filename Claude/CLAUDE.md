# Espace de travail : fabrication de decks

- Réponds en français.
- Pour tout deck, slide ou présentation, utilise le skill `deck-builder`.
- Dossiers : `decks/` (specs JSON, source de vérité), `sortie/` (pptx et pdf générés), `modeles/` (modèles PowerPoint de l'entreprise), `sources/` (documents d'entrée).
- Pas d'accès web : n'utilise que les documents présents dans le dossier et ce que je te dis. Toute donnée manquante devient `[À COMPLÉTER]`.
- Pas de tiret cadratin dans les textes : virgule ou deux-points.
- Poste macOS : scripts en bash, Python via `.venv/bin/python` ou `python3`.
